# シナリオライブラリ

## プレイ可能なオリジナル作品

- `original/neon-ledger.json`: **ネオンの帳簿**（10シーン、選択肢、分岐、手がかり、ハンドアウト、遭遇）。全文章と登場人物は独自制作。
- GM画面の「シナリオ」→「JSON取り込み」でファイルを取り込み、その後「シナリオ進行」から選択して開始する。既存の `POST /api/scenarios/import` と進行エンジンを利用。
- 難易度、武器能力値、報酬、敵の戦闘能力値は憶測で設定していない。エンカウンターの participants は空なので、PC/NPCデータを作成・関連付けするまで戦闘自動投入はできない。
- 判定で自動分岐させたい場合、シナリオメーカーで技能と難易度を設定する。初期状態の選択肢はGMの判断でシーン移動する。

## 外部公開シナリオ

`external-catalog.json` は参照用リンク。**本文・分岐・敵データを取得したものではない**ため、そのままプレイ可能なシナリオではない。原作通りの実装には各配布元のテキストを入手し、権利・利用条件を確認してから個別に構造化すること。

## QA / 制限

- 既存スキーマ `ScenarioFullSchema` の required fields に合わせて構成。
- 既存のJSON importはIDを振り直し、同名のシナリオの重複取り込みを防がないので、二重取り込みに注意。
- エンカウンターは人数メモのみで、実際の戦闘投入はNPCを紐づけてから行う。
