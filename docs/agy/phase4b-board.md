## ゴール

Phase 4a の戦闘画面に **盤面** を入れる。コマを動かすと移動できるマスが出て、射撃では射線と距離が自動で決まり、4a で GM が手で入れていた距離が盤面から入る。同じ戦闘を **別ウィンドウ**（`/gm/combat`）と **TV**（`/screen`）にも出す。

シナリオ側のステージ（シーンごとの背景・初期配置の保存、視界を隠す、シナリオメーカー）は Phase 5。ここでは戦闘タブの盤面だけを作るが、**Phase 5 で同じ部品を使える形**（盤面のデータとコンポーネントを戦闘から切り離す）にする。

## 1. データ（drizzle のマイグレーションを追加）

| テーブル | 列 |
|---|---|
| `boards` | id, name, background_image_id null, grid(JSON: show, cell_m, origin_x, origin_y, cell_px, cols, rows), created_at, updated_at |
| `board_objects` | id, board_id, kind（wall / crate / container / vehicle / other）, label, x, y, w, h（マス単位）, rotation（0 / 90 / 180 / 270）, passable, blocks_los（none / partial / full）, cover_hp null, cover_hp_max null |
| `board_tokens` | id, board_id, character_id, x, y, gm_only |
| `board_drops` | id, board_id, x, y, inventory_entry(JSON), from_character_id |

- `combats` に `board_id null` を足す。戦闘を始めるとき、盤面を選ぶ（なしでもよい。なしなら 4a と同じく距離を手で入れる）
- 1 マスの距離 `cell_m` の既定は 2（SPEC §5.3.1。確認済みの MOVE × 2m と同じ）
- **遮蔽物の HP は既定値を入れない**（Issue #5 で確認中）。GM が置くときに入れる。空なら「HP 不明」と出す
- 保存ファイル（cpgm-save）の `version` を 4 に上げ、盤面の 4 テーブルを含める。1〜3 も読めるようにする

## 2. 盤面の表示と編集（戦闘タブ。モック「GM — 戦闘」の中央）

- 背景画像（`/api/images/:id?t=`）、グリッド（表示の切り替え、背景に合わせて原点とマスの大きさを調整）
- コマ: 参加者のサムネイル（4a と同じ。なければ頭文字を味方色 `#4FB6E3`・敵色 `#F28C38`）、下に HP バー（味方色/敵色 → 黄=重傷 → 赤=瀕死）、致命傷・落とした物の印、死亡・離脱はグレー。手番中のコマを強調
- 「GM のみ」のコマは GM の盤面では半透明で出し、別ウィンドウ以外（TV・スマホ）には送らない
- オブジェクト: 戦闘外（`combats.status` が setup か戦闘なし）はドラッグで移動・サイズ変更・90 度ずつ回転・削除。**戦闘中は固定**
- 拡大・縮小とスクロール。スマホ幅（390px）でも盤面を見られる（操作は PC 前提でよい）
- 実装は SVG か canvas。外部ライブラリを足すなら報告に書く

## 3. 移動（SPEC §5.1「移動」）

- 「移動」ボタン（4a の `move`）を押すと、移動できるマスを青く出す。歩ける距離は `packages/rules` の `moveSquares`、距離の数え方は `gridDistance`（斜めの数え方は `rule_constants` の `diagonalRule`。Issue #10 で確認中。既定 chebyshev）
- **壁（passable = false）は通れない**: マスの到達判定は、通れないマスを避けた最短経路（BFS など）で数える。直線距離だけで決めない
- 他のコマのマスには止まれない（通り抜けは可とする。止まれないことだけ実装し、通り抜けの可否は報告に「ルール確認が必要」と書く）
- 移動先をクリック、またはコマをドラッグ →「移動を確定」で、4a の「確定して反映」に通す（`combat_log` に記録、取り消せる）
- 「走る」（`run`）は同じ範囲をもう一度
- GM の **強制移動**: 移動範囲を無視して置ける（ログに「強制移動」と残す）
- 戦闘外ではコマを自由にドラッグできる

## 4. 射線と距離（SPEC §5.1「射線」）

- 射撃・照準射撃・オートファイアで対象を選ぶと、撃つ側のマスの中心から対象のマスの中心へ線を引く
  - 緑 = 通る、黄 = `blocks_los = partial` のオブジェクトを通る（遮蔽物越し。遮蔽物の名前と HP を出す）、赤 = `full` に遮られて撃てない
  - 線が通るマスの判定は、線分とオブジェクトの矩形（回転後）の交差で行う。角をかすめる場合の扱いは報告に書く
- 対象の選択欄にも「射線○ / 遮蔽越し / 射線×」と距離（m）を出す
- **距離**: 4a の距離（m）の欄に、`gridDistance × cell_m` を自動で入れる。GM は上書きできる
- **遮蔽物越しの扱いは自動で計算しない**（Issue #5: 先に遮蔽物に当たるか、遮蔽物の HP の値が未確認）。黄のときは手順の上に「遮蔽物越し（ルール確認中 Issue #5）。遮蔽物に当てるかは GM が決める」と出し、GM が「遮蔽物に当てる」を選んだら、ダメージを遮蔽物の `cover_hp` から引く欄を出す（HP が空なら GM が入れる）。0 になったら遮蔽物を壊れた表示にし、`blocks_los` を none にする（取り消しで戻す）
- GM は射線の判定を上書きできる（「通る / 遮蔽越し / 撃てない」を手で選ぶ）
- 近接攻撃・格闘は隣のマス（距離 1 マス）の対象だけ選べる。離れていれば理由を出してグレーにする

## 5. 落とした物（4a の「落とした物」）

- 照準射撃で落とした物を、落とした参加者のマスに置く（`board_drops`）。盤面に印を出す
- 「拾う」（`pickup`。Issue #4 で unconfirmed）は 4a どおり GM の手入力だが、隣か同じマスの落とし物を選んで「拾う」と所持品に戻せるようにする（ログに残す・取り消せる）

## 6. 別ウィンドウ `/gm/combat`（モック「GM — 戦闘（別ウィンドウ）」）

- 戦闘タブの「別ウィンドウで開く」で `window.open`。行動順バー・盤面・手番の参加者カード・ターン進行ガイドを、コンパクトな配置で出す
- GM 画面と同じ状態（WebSocket の `combat:update` と盤面の更新）。どちらで操作しても両方が変わる
- 権限は GM（4a と同じトークン）

## 7. TV の共有画面 `/screen`（モック「共有画面」）

- 操作はできない。GM が戦闘タブで「TV に出す」をオンにしたときだけ表示する
- 出すもの: 盤面（背景・グリッド・オブジェクト・コマ）、行動順、ラウンド、味方の HP（数値とバー）、**敵は名前と負傷状態だけ**（4a のプレイヤー向けと同じ出し分け。HP・SP の数値は送らない）
- 出さないもの: 「GM のみ」のコマ、`status` に「隠れている」がある敵のコマ（Issue #15 で範囲を確認中なので、この 2 つだけ隠す。足りない分は報告に書く）、GM の数値・ログ・手順
- 背景画像の `visibility` が `gm`（本のスキャン）のときは TV に出さない。GM の画面に「この背景は GM のみの画像です。TV に出すには公開設定を変えてください」と出す（SPEC §3）
- `/screen` の入り方: GM 画面の「TV 用の URL」（QR と同じセッションコード入り）。サーバ側で、送る情報を上の範囲に絞る（ブラウザ側で隠すだけにしない）
- **ログイン・PIN を足さない**

## 8. API・WebSocket（入出力は zod）

- `GET/POST/PATCH/DELETE /api/boards`、`/api/boards/:id/objects`、`/api/boards/:id/tokens`（GM だけ）
- `POST /api/combats/:id/resolve` と `apply` に、移動先・射線の判定（自動か上書きか）・遮蔽物に当てたかを足す。**サーバ側で経路と射線を計算し直す**（クライアントの判定をそのまま信じない）
- WebSocket: `board:update`（GM と別ウィンドウ）、`screen:update`（TV。§7 の範囲だけ）。プレイヤーのスマホには盤面を送らない（SPEC §5.0。スマホは自分のキャラシートと行動だけ）

## 9. テスト

- 単体
  - 経路: 壁を回り込む必要があるマスは、直線では届いても MOVE の範囲外になる。ほかのコマのマスには止まれない
  - 射線: 何もない → 通る、partial の木箱 → 遮蔽越し、full の壁 → 撃てない、回転したオブジェクト
  - 距離: (0,0)→(3,4) が chebyshev で 4 マス = 8m（`diagonalRule` を変えると変わる）
  - 遮蔽物: GM が「遮蔽物に当てる」を選ぶと `cover_hp` が減り、0 で `blocks_los` が none、取り消しで戻る
  - TV: `screen:update` に敵の `hp`・`sp`、GM のみのコマ、隠れている敵が入っていない
  - 保存: version 4 の保存と読み込み、1〜3 の読み込み
- E2E: 盤面を作る（背景・壁・木箱）→ コマを置いて戦闘開始 → ヴァイパーが移動（壁の向こうに行けない）→ 射撃で距離が自動で入り、木箱越しが黄色 → 確定 → 別ウィンドウと TV に同じ結果が出る（TV に敵の HP の数値がない）
- スクリーンショット: 盤面つきの戦闘画面で移動範囲と射線（1440px）、別ウィンドウ（1280px）、TV（1920px）、盤面の 390px

- プレイヤーのスマホへの盤面の表示（SPEC §5.0）
- 爆発物・範囲攻撃の範囲表示（Issue #14）
- ログイン・パスワード・PIN など、指示書にない仕組み
