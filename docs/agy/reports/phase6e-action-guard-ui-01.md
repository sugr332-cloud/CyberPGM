## 実施したこと

指示書 A〜G を実装しました。ルールの計算は変更していません。指示書末尾の G も作業ブランチに含めています。

- A: 〈武術〉を 1 レベル以上持たないキャラクターの「武術攻撃」「武術奥義」を GM・スマホ両方で無効化し、同じ理由を表示します。サーバー解決時にも同じ理由で拒否します。追加した装備・状態ガードは、近接武器を持たない「近接攻撃」、射撃武器がない射撃系、対応武器・残弾がないフルオート／制圧射撃、予備弾薬がないリロード、未乗車・運転席・未始動などの車両行動です。既存の行動可否理由も GM のボタンとスマホに表示します。応急手当は技能 0 でも選択できます。
- B: 解決結果に `missing_fields` を追加し、文言ではなく欄 ID で攻撃・回避・ダメージ・致命傷・死亡セーヴや対象・武器・距離などの不足欄を赤枠表示します。入力後は枠が消えます。既存の `missing_inputs` 文言は保持しています。
- C: GM・スマホの格闘と武術攻撃に `combatDamageFormula` 由来のダメージ式を表示します。出目欄の近くにもダメージ式の説明を出します。
- D: GM・スマホの行動一覧から個別の車両行動をまとめ、「車両」ボタンの先に全 8 行動と戻るボタンを表示します。車両状態に応じた理由を出し、「乗る」だけが選べる状態を確認しました。
- E/G: `packages/shared/src/combat-ui.ts` に戦闘行動 42 キー分の入力定義を置き、GM の判定欄とスマホの出目パッドが同じ定義を使います。NET のサブアクションと環境ダメージの種類にも個別定義を用意しました。選んだ行動にない欄は表示しません。「受け方」は回避が可能な遠隔攻撃で対象 REF が 8 以上の場合だけ表示します。

### E: ダイス表示の変更前・変更後

| 行動 | 変更前 | 変更後 |
|---|---|---|
| 応急手当 | 汎用の攻撃・ダメージ・致命傷欄が表示され、回避欄も状態によって表示 | 行動者の応急手当判定 1d10 のみ |
| 死亡セーヴ | 汎用の攻撃・ダメージ・致命傷欄が併存 | 行動者の死亡セーヴ 1d10 のみ |
| 格闘・武術 | 「攻撃」「回避」など汎用名。行動ボタンにダメージ式なし | 行動者の命中判定、対象の回避、命中時ダメージ等を役割つきで表示。ボタンと出目ガイドに実ダメージ式 |
| 射撃 | 攻撃・回避・ダメージ・致命傷が一律表示 | 命中、条件を満たした対象の回避、命中時ダメージ、条件成立時の致命傷だけ |
| 車両・環境・その他 | 行動の種類を問わず汎用出目欄が残る場合があった | 上表の該当欄のみ。行動の種類・条件で切替 |

G 追加前は攻撃・ダメージ・致命傷の汎用欄が全行動に出ていました。余分だった行動は、表の「出目なし」の行動（移動、遮蔽、制圧射撃、締め、投げ、放す、リロード、身を隠す、走る、拾う、技能、アイテム、ソロ再配分、車両の乗降・始動・停止、NET の出目なしサブアクション、環境状態終了、その他）に加え、応急手当・死亡セーヴ・回避・スキャナー・操縦など攻撃／ダメージ／致命傷の一部を使わない行動でした。対象の回避欄も、回避を選べない行動や対象の REF が条件未満の遠隔攻撃では余分でした。
