- 報告: `docs/agy/reports/phase5e-stage-display-<連番>.md`
- 前提として読むもの: `docs/SPEC.md` §3 権利、§5.0、§5.3.1 ステージ、`docs/agy/phase4b-board.md`（別ウィンドウ・TV）、`docs/agy/phase5b-scenario-play.md`（背景の表示）

## ゴール（2026-10-21 ユーザー決定）

1. ストーリーの場面で、GM が用意した画像（背景）を **別ウィンドウ** に出し、その上に **立ち絵** を置ける
2. 立ち絵と NPC を選ぶ画面（操作の部分）は **GM のメインウィンドウだけ**。別ウィンドウには出さない（別ウィンドウは見せる絵だけ）
3. 戦闘中も、別ウィンドウのマップに **あとからプレイヤーと NPC を足せる**

## 1. 表示ウィンドウ（別ウィンドウ）

- 表示ウィンドウは Phase 4b の共有画面 `/screen` を使う。GM 画面に「表示ウィンドウを開く」ボタン（`window.open`。TV に映してもよい）
- 中身はモードで切り替わる: **ストーリー** = 背景 + 立ち絵、**戦闘** = 盤面（4b のまま）。GM が「ストーリー / 戦闘」を切り替える。戦闘を始めると自動で戦闘、終えるとストーリーに戻る
- 表示ウィンドウには操作のボタン・選択欄・GM の数値を一切出さない（見せる絵だけ。全画面にできる）
- 送る情報はサーバで絞る（4b と同じ。GM のみの画像・GM のみのコマは送らない）

## 2. ストーリーの舞台（背景と立ち絵）

- GM のシナリオタブ（進行モード）に「舞台」パネルを置く。**このパネルは GM のメインウィンドウだけに出す**（表示ウィンドウ・戦闘の別ウィンドウ `/gm/combat`・スマホには出さない）
- **背景**: 画像の一覧（5a の `GET /api/images`）から選ぶ。シーンの背景（5a）を初期値にする
- **立ち絵**:
  - キャラクター（PC・NPC）に `portrait_image_id`（立ち絵）を足す。サムネイル（`image_id`）とは別。PC タブと NPC の編集で、画像の一覧から選ぶかアップロードする（透過 PNG をそのまま使う。Phase 3a のアップロードの制限）
  - 舞台パネルで「登場させるキャラ」を一覧から選ぶ（立ち絵があるキャラだけ）。選ぶと表示ウィンドウの背景の上に出る
  - 置き方: ドラッグで位置、拡大・縮小、左右反転、前後の順番、名前の表示の有無。「左・中央・右」のボタンで素早く置ける
  - 「退場」で消す。「全員退場」
  - 配置はシーンごとに保存し（`scenes.stage`(JSON)）、シーンに戻ると前の配置になる
- **本のスキャンの画像**（`visibility = gm`）は表示ウィンドウに出せない（4b と同じ警告）。GM が画像ごとに「プレイヤーにも見せる」に切り替える欄を、画像の一覧に置く（SPEC §3「プレイヤー端末にも出すかは GM が画像ごとに決める」）。切り替えるときに「本のスキャンは私的利用の範囲で使ってください」と一度だけ確認を出す
- スマホには、5b の「GM からの表示」で背景だけ出す（立ち絵は出さない。表示ウィンドウ専用）

## 2.5 シーンの BGM と、シーンのクリックでの切り替え（2026-10-21 ユーザー決定）

- 進行モードで **シーンをクリックすると**、表示ウィンドウにそのシーンの背景（と保存した立ち絵の配置）が出て、そのシーンに設定した **BGM が流れる**
- 音声ファイルの登録: GM が mp3 / ogg / m4a / wav をアップロードする（上限 30MB。拡張子と中身の先頭のバイトを確かめる）。保存先は `data/audio/user/`、git に入れない。音声の一覧（タイトル・長さ）。テーブル `audio`（id, title, path, duration_sec, created_at）
- シーンの設定（5a のシーンの編集）に「BGM」を足す: 音声を選ぶ・ループするか・音量（0〜100）。`scenes.bgm`(JSON: audio_id, loop, volume)。BGM なしのシーンに移ったら止める（GM の設定で「前の曲を流し続ける」も選べる）
- 曲の切り替えは 1〜2 秒でフェードする（ぶつ切りにしない）
- GM のメインウィンドウの舞台パネルに、再生・停止・音量・曲の選び直し（その場だけ）。この操作も表示ウィンドウには出さない
- 音を鳴らすのは **表示ウィンドウだけ**（GM のメインウィンドウ・戦闘の別ウィンドウ・スマホでは鳴らさない）
- ブラウザは操作なしで音を鳴らせないので、表示ウィンドウを開いたときだけ「クリックして音声を有効にする」を 1 回出す（押したら消える。表示ウィンドウの操作はこれだけ）
- 戦闘中の BGM: 戦闘の設定で曲を選べる（なしなら、そのシーンの曲を流し続ける）
- テスト: シーンをクリック → 表示ウィンドウに背景と `audio` の要素（src・loop・音量）が届く。BGM なしのシーンで止まる。GM のウィンドウとスマホには `audio` の要素がない。不正な音声ファイル（拡張子と中身が違う、上限超え）は拒否

## 3. 戦闘の途中参加（プレイヤーと NPC をあとから足す）

- 戦闘中（`combats.status = active`）の戦闘画面に「参加者を足す」ボタン。4a の参加者チェックと同じ選択（PC・DB の NPC・モブと人数・味方か敵か）
- 足した参加者のイニシアチブは 4a どおり（NPC は自動ロール、PC はスマホかこの画面で出目）。今のラウンドの行動順に差し込む
- 盤面があれば、コマを置く場所を盤面のマスのクリックで選ぶ（空いたマスだけ。置かなければ「未配置」に入れ、あとで「未配置の参加者コマを配置」で置ける）
- 足した結果は、GM の戦闘画面・戦闘の別ウィンドウ `/gm/combat`・表示ウィンドウ `/screen`（敵は名前と負傷状態だけ）・該当プレイヤーのスマホに同時に反映される
- 「退場させる」（逃げた・離脱した）も同じ画面から。コマはグレーになり、手番を飛ばす（4a）
- 戦闘ログに「途中参加」「退場」を残す。取り消せる

## 4. テスト

- 表示ウィンドウ: ストーリー時に背景と立ち絵が出る。操作のボタン・選択欄が DOM にない。戦闘開始で盤面に切り替わる
- 立ち絵: 位置・拡大・反転・順番・退場が表示ウィンドウに反映される。シーンを移って戻ると配置が戻る
- 権限: `visibility = gm` の画像は表示ウィンドウに送られない。切り替えたら送られる。スマホに立ち絵が送られない
- 舞台パネルが `/gm/combat` と `/screen` に出ない
- 途中参加: 戦闘中に NPC を 1 体足すと、行動順に入り、盤面の選んだマスに置かれ、別ウィンドウと表示ウィンドウに出る。PC を足すと、そのプレイヤーのスマホに手番と行動が出る。取り消しで元に戻る
- E2E: 進行モードで背景を選び、立ち絵を 2 人置く → 表示ウィンドウに出る（操作の欄はない）→ 戦闘開始 → 戦闘中にモブを 2 体足して盤面に置く → `/gm/combat` と `/screen` に出る
- スクリーンショット: 舞台パネル（1440px）、表示ウィンドウのストーリー（1920px）、戦闘中の途中参加（1440px）、表示ウィンドウの戦闘（1920px）

## 5. やらないこと

- スマホへの立ち絵の表示
- ログイン・パスワード・PIN など、指示書にない仕組み
