## A. 資料（世界観・年表・フレーバー）を GM ツールで見る・探す

### サーバー

- `loadLoreData()` を作る（`loadRoleData()` と同じ方法）。ファイルがなければ `{ entries: [] }`
- `GET /api/lore`（GM 専用）
  - クエリ: `q`（検索語）, `category`
  - 検索は `title`, `summary`, `body`, `tags`, `year` を対象に、空白で区切った語をすべて含むものを返す（大文字小文字・全角半角の英数字は区別しない）
  - 並び: 年表は `year` の古い順、それ以外は `pages` の小さい順
  - ファイルがないときは `{ entries: [], hasSource: false }`
- 既存の全文検索 `GET /api/search` に資料も入れる。種類は `lore`、`title` は項目名、`sub` は分類名と年

### 画面（GM ページに「資料」タブ）

- `apps/web/src/pages/GmPage.tsx` のタブに `{ id: 'lore', label: '資料' }` を足す（PC 版とスマホ幅の両方の並び）
- 新しい部品 `LoreView.tsx`:
  - 上に検索欄と、分類の絞り込み（すべて／年表／世界観／…）
  - 左に一覧（項目名・分類・年・ページ）、右に選んだ項目の中身（要約、箇条書き、タグ、関連項目へのリンク、参照ページ）
  - 年表は一覧を年の順に、年を目立たせて出す
  - 検索語に当たった部分を強調する
  - 390px 幅でも使える（一覧と中身を縦に並べる）
  - ファイルがないときは「世界観の資料（手元のルール資料）がありません」
- 全文検索で資料を選んだら「資料」タブに移り、その項目を開く
- シナリオ作成で使えるように、項目の中身の横に「コピー」ボタン（要約と箇条書きをテキストでクリップボードへ）。シナリオ側への自動の取り込みは作らない

## B. ルールブックの NPC を登録する

### サーバー

- `loadNpcTemplates()`（`npcs.json` を読む。なければ空）
- `GET /api/npc-templates`（GM 専用）: 一覧と `tiers`
- `POST /api/npc-templates/:key/register`（GM 専用）: そのテンプレートから NPC のキャラを 1 体作る
  - `characters` に `kind = 'npc'` で作る。名前は本のとおり。同じ名前があれば「ボディガード 2」のように番号を付ける
  - 能力値、HP（`hp` と `hp_max`）、頭部・身体の SP、防具の名前は本のとおり
  - **技能**: アプリは「能力値＋技能レベル＋1d10」で計算するので、技能レベル = 技能基本値 −（その技能の能力値）にする
    - 日本語の技能名からキーへは、既存の `skillNameToKey` と `SPECIALIZED_SKILLS`（`言語：母語` → `language:母語` など）を使う
    - 引き算が 0 未満になるときは 0 にし、作成結果の「注意」に名前を出す
    - 見つからない技能名は登録せず、「注意」に出す
    - ロール特技（`インターフェイス`、`モト`、`コンバット・アウェアネス`）は技能にせず、`role` と `extra.role_ranks` に入れる
    - 警備隊の士官の `skills_with_armor` は使わない（防具ペナルティはアプリが計算する）
  - **武器**: `weapons` の名前で既存の品目（`items`）を探して所持品に入れる（`WEAPON_NAME_ALIASES` も使う。「低品質の〜」は品質を低品質にする）。見つからない武器は、名前とダメージだけの所持品にして「注意」に出す
  - **装備・サイバーウェア・プログラム**: `gear` と `programs` は、品目が見つかれば所持品に、なければ `notes` に文字で残す
  - `extra.npc_template = key` を入れる（どのテンプレートから作ったか）
  - 返り値: 作ったキャラと「注意」の一覧
- 登録は何度でもできる（同じテンプレートから複数体作れる）

### 画面

- 「キャラ作成」タブ（`CharacterEditorView`）の NPC を作るところに「ルールブックの NPC から作る」ボタン
  - 一覧（名前・ランクの目安〈雑魚／幹部／小ボス／ボス〉・HP・SP・主な武器・ページ）を出し、「登録」で作る
  - 作ったら、そのキャラを開き、「注意」があれば出す
  - `tiers` の目安（雑魚は PC と同じ人数、幹部は 2 人に 1 人、など）を一覧の上に出す
- 戦闘に入れる手順は既存のとおり（作った NPC を参加者に足す）

## テスト

- 単体:
  - `/api/lore`: ファイルあり・なし、検索（複数語・タグ・年）、分類の絞り込み、年表の並び
